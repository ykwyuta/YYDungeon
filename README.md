# 迷宮工房 · YYDungeon

ゴブリン工務隊に命令を出して迷路を広げ、宝箱で冒険者をおびき寄せるダンジョン運営ゲームです。

## 起動

Windows 版は Rust と MSVC のビルド環境で起動します。

```powershell
cargo run --locked --release --bin yydungeon-win
```

ブラウザ版は Rust、Node.js、プレビュー用の Python を使います。npm パッケージのインストールは不要です。

```powershell
rustup target add wasm32-unknown-unknown
node tools/build.mjs
python -m http.server 8765 --bind 127.0.0.1 --directory dist
```

[http://127.0.0.1:8765/](http://127.0.0.1:8765/) を開きます。スマートフォン・タブレットでは横向きで遊べます。GitHub Actions からも Windows の実行ファイルとブラウザ用の静的ファイルを取得できます。

## Cloudflare 配信

Cloudflare Workers は他の YY シリーズと同じく静的アセットのみを配信します。`wrangler.toml` の Worker 名は `yydungeon`、公開ディレクトリは `dist` です。

```bash
npx wrangler deploy
```

Workers の Git 連携ではルートをリポジトリの直下、デプロイコマンドを `npx wrangler deploy` にします。Wrangler が `wrangler.toml` のビルド設定から `bash build.sh` を実行して `dist` を生成するため、管理画面のビルドコマンド欄は空欄で構いません。Cloudflare Pages を使う場合は、ビルドコマンドを `bash build.sh`、出力ディレクトリを `dist` に設定します。

## 遊び方

スタート画面の「はじめる」で工房に入ります。保存がある場合は「つづきから」で再開できます。

1. 右の工務隊で指示を選び、迷路の区画をクリックまたはタップします。宝箱、モンスター、罠は通路に置けます。迷路下の凡例で岩の種類を確認できます。掘削できる岩はひび割れた琥珀色、設置した岩壁は青い石積み、掘削できない岩は黒い一枚岩です。外壁と通路に接していない自然岩は掘削できません。「岩壁を置く」（8）で空き床を塞いで通路を変えられます。入口から通路全体への道は残す必要があります。「撤去」（7）は岩壁・宝箱・罠・仲間を片付ける指示で、金貨8を使います。罠は種類ごとに設置回数を記録し、次に置く罠の威力と設置費が上がります。
2. 運営中のフロアに宝箱を置くと冒険者が来ます。箱を増やすと人数が増えます。開けられた宝箱は消え、最後の箱を失うと再設置するまで次の襲撃は始まりません。すでに侵入中の冒険者は行動を続けます。並品の宝箱は金貨20です。運営中の階に箱がなく、金貨が足りない場合、最初の並品の宝箱は工務隊が不足分を補います。襲撃の最大レベルは波数と到達階で決まります。地下3階から、階が深くなるごとに最大レベルが2、冒険者のHPが8、玉座戦の攻撃ダメージが2ずつ上がります。罠や仲間で削ったHPは玉座戦に持ち越されます。襲撃開始時にいちばんレアな宝箱が、その波の撃退報酬を決めます。並品を100%として、金貨は上物135%、希少175%、伝説225%です。戦利品も増え、希少以上では骨材も増えます。冒険者はチンピラから勇者まで12職。次の襲撃に来る最高位の職が表示され、迷路上の冒険者を選ぶと職とHPが確認できます。宝箱を調べると入口から宝箱までの予想経路を確認できます。冒険者は罠や生きている守備モンスターを避け、安全な経路がなければ危険箇所が少ない道を選びます。宝箱を開けた後は玉座を目指します。
3. 42秒ごとに襲撃が始まります。守備モンスターは通路で冒険者を足止めし、最大3回の攻防を行います。迷路上のHPゲージはモンスターが青緑、冒険者が赤です。「冒険者を呼び込む」で早めることもできます。撃退した冒険者の死体から骨材を集め、持ち物と金貨を回収します。強い冒険者ほど報酬が増えます。玉座まで通すと専用のターン制画面に移ります。魔王の攻撃・魔法・防御を選びます。同じ襲撃内ではMPを次の玉座戦に持ち越し、戦いの後と防御で最大2ずつ回復します。次の襲撃ではMPが満タンに戻ります。レベルに応じて技と威力が変わり、冒険者は負傷すると逃げることがあります。魔王のHPが0になるとゲームオーバーです。
4. その階で6人、14人を撃退すると迷路と配置上限が広がり、金貨と宝箱のレア度が増えます。玉座で魔王が自ら冒険者を倒すと経験値を得ます。地下2階はボスLv.3、地下3階はLv.5と、以降も必要レベルが2ずつ上がります。準備中に次のフロアを開けます。工房日誌には魔王のレベル、次のレベルまでの残り経験値、次の階に必要なレベルが表示されます。
5. 内壁を掘ると「迷宮開発」が進みます。枝分かれを増やしたり、別々の通路をつないで回り道を作ったりすると、行き止まりを延ばすより開発が進みます。右側の「仲間モンスター図鑑」にはスライム、ゴーレム、ドラゴンなど全40種が並びます。仲間にできる種は、到達階と累計の開発ポイントで決まります。地下1階ではゴブリン、スライム、洞窟コウモリを配置できます。地下2階から1フロアにつき最大2種が加わり、全40種が揃うのは地下20階です。上位ランクの配置は金貨と骨材を多く使い、B以上は戦利品も使います。
6. 上層を中ボスの氷の主に任せると迎撃と回収を自動で行います。表示されたレベル以上の冒険者や迎撃しきれなかった冒険者は下の階へ向かいます。隊長とその同行者は運営中の階まで進みます。階の切り替えは画面左上の矢印を使います。

上部の「秘書の助言」でレイラが次の襲撃や迷宮の開発について助言します。執事セヴランは襲撃が終わるたびに戦果を報告し、「執事の戦果」から読み直せます。玉座の戦いは **1〜4** で技を選び、決着後は **Enter** で進みます。魔王と冒険者12職は、攻撃・必殺技・被弾などで専用の戦闘姿勢に切り替わります。

**キー操作**　F1 遊び方 / 1〜8 建設指示 / Enter 襲撃開始 / Space 一時停止 / ← → フロア切り替え / Esc 指示・案内を閉じる / F11 全画面。

ブラウザ版の「遊び方」から「キャッシュを消して再読み込み」を選ぶと、進行を保存してゲームファイルを取り直せます。

両版とも進行を自動保存します。Windows は `%APPDATA%\yydungeon\dungeon.json`、ブラウザはサイト単位のローカルストレージを使います。

## 共通ソース

`src/dungeon.rs` が迷路・建設・戦闘・進行・保存形式を、`src/screen.rs` が画面と操作を担当します。同じ Rust を Windows 実行ファイルと WebAssembly にビルドし、Windows は YYHistory 由来の Direct3D11・Direct2D・DirectWrite、Web は Canvas 2D に描画します。画像は両版に同梱します。[画像素材と生成プロンプト](assets/README.md)

```powershell
cargo test --locked --lib
node tools/build.mjs
node tools/wasm-smoke.mjs
```
